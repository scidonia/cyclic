\subsection{Cyclic proof for reverse-append fusion}
\label{sec:reverse-append-proof}

\begin{figure}[t]
\centering
\tiny
\[
\AxiomC{$
  xs, ys : \mathsf{List}
  \vdash
  \mathsf{reverse}\;(\mathsf{append}\;xs\;ys)
  : \mathsf{List}
  \;\textcolor{red!70}{\dagger}
$}
\RightLabel{\;\textsc{fix}$+\beta$}
\UnaryInfC{$
  xs, ys : \mathsf{List}
  \vdash
  \mathsf{revAcc}\;(\mathsf{append}\;xs\;ys)\;\mathsf{nil}
  : \mathsf{List}
$}
\RightLabel{\;\textsc{lemma}}
\UnaryInfC{$
  xs, ys : \mathsf{List}
  \vdash
  \mathsf{revAcc}\;ys\;(\mathsf{reverse}\;xs)
  : \mathsf{List}
$}
\RightLabel{\;\textsc{fix}$+\beta$}
\UnaryInfC{$
  xs, ys : \mathsf{List}
  \vdash
  \mathsf{case}\;ys\;\mathsf{of}\;
  \{\mathsf{nil}{\to}\mathsf{rev}\;xs\;;
    \mathsf{cons}\;y\;ys'{\to}\mathsf{revAcc}\;ys'\;(\mathsf{cons}\;y\;(\mathsf{rev}\;xs))\}
  : \mathsf{List}
$}
\DisplayProof
\]

\[
\AxiomC{$xs,ys \vdash \mathsf{reverse}\;xs : \mathsf{List}$}
\RightLabel{\;\textsc{back}\;\textcolor{red!70}{\dagger}}
\UnaryInfC{\textcolor{red!60}{$
  xs,ys \vdash \mathsf{reverse}\;(\mathsf{append}\;xs\;\mathsf{nil}) : \mathsf{List}
  \;\textcolor{red!70}{\dagger}
$}}
\RightLabel{\;\textsc{nil}}
\quad
\AxiomC{$
  xs,y:\mathsf{Nat},ys':\mathsf{List}
  \vdash
  \mathsf{revAcc}\;ys'\;(\mathsf{cons}\;y\;(\mathsf{reverse}\;xs))
  : \mathsf{List}
$}
\RightLabel{\;\textsc{cons}}
\BinaryInfC{$
  xs,ys : \mathsf{List}
  \vdash
  \mathsf{case}\;ys\;\mathsf{of}\;
  \{\mathsf{nil}{\to}\mathsf{rev}\;xs\;;
    \mathsf{cons}\;y\;ys'{\to}\mathsf{revAcc}\;ys'\;(\mathsf{cons}\;y\;(\mathsf{rev}\;xs))\}
  : \mathsf{List}
$}
\RightLabel{\;\textcolor{red!70}{\textsc{split}\;$\star$}}
\DisplayProof
\]

{\tiny
\textbf{Fig.~\ref{fig:reverse-append-proof}.}
Two-part derivation (top = driving phase; bottom = split).
$\mathsf{rev}\;xs = \mathsf{reverse}\;xs$ abbreviated.
$\dagger$ = backlink target; red = companion; $\star$ = progress.
\textsc{lemma}: LLM cut $\mathsf{revAcc}\;(\mathsf{append}\;xs\;ys)\;acc = \mathsf{revAcc}\;ys\;(\mathsf{revAcc}\;xs\;acc)$.
Nil branch closes via \textsc{back} ($ys{\mapsto}\mathsf{nil}$, hence
$\mathsf{reverse}\;(\mathsf{append}\;xs\;\mathsf{nil}) = \mathsf{reverse}\;xs$).
Cons branch drives further through $ys'$ by structural induction.
}
\label{fig:reverse-append-proof}
\end{figure}

Without the \textsc{lemma} rule, the step from
$\mathsf{revAcc}\;(\mathsf{append}\;xs\;ys)\;\mathsf{nil}$
to $\mathsf{revAcc}\;ys\;(\mathsf{reverse}\;xs)$ is blocked:
the two terms do not anti-unify, and no fold is possible.
