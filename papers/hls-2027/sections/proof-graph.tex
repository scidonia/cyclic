\subsection{Cyclic proof for reverse-append fusion}
\label{sec:reverse-append-proof}

Figure~\ref{fig:reverse-append-proof} shows the cyclic proof.
The root goal (bottom) is $\mathsf{reverse}\;(\mathsf{append}\;xs\;ys) : \mathsf{List}$.
Driving (\textsc{fix}) and the LLM-proposed lemma (\textsc{lemma}) reduce it to
$\mathsf{revAcc}\;ys\;(\mathsf{reverse}\;xs)$.  The split on $ys$ ($\star$,
progress event) yields a nil branch that closes via a backlink --- the
goal $\mathsf{reverse}\;xs$ is an instance of the root under the
substitution $ys\mapsto\mathsf{nil}$ --- and a cons branch (green, proved
by structural induction on $ys'$).

\begin{figure}[t]
\centering\scriptsize
\begin{prooftree}
  \hypo{ys \mapsto \mathsf{nil} \;:\; [ys] \to_s [xs,ys]}
  \infer1[\textsc{back}\;\textcolor{red!70}{\dagger}]{
    \textcolor{red!60}{
      xs,ys \vdash \mathsf{reverse}\;(\mathsf{append}\;xs\;\mathsf{nil}) : \mathsf{List}
      \;\textcolor{red!70}{\dagger}
    }
  }
  \hypo{\textcolor{green!60!black}{
    xs,y{:}\mathsf{Nat},ys' \vdash
    \mathsf{revAcc}\;ys'\;(\mathsf{cons}\;y\;(\mathsf{reverse}\;xs)) : \mathsf{List}
    \;\text{(see Fig.~\ref{fig:cons-branch})}
  }}
  \infer2[\textsc{iota}]{
    xs,ys \vdash \mathsf{revAcc}\;ys\;(\mathsf{reverse}\;xs) : \mathsf{List}
  }
  \infer1[\textsc{lemma}]{
    xs,ys \vdash \mathsf{revAcc}\;(\mathsf{append}\;xs\;ys)\;\mathsf{nil} : \mathsf{List}
  }
  \infer1[\textsc{fix}]{
    xs,ys \vdash \mathsf{reverse}\;(\mathsf{append}\;xs\;ys) : \mathsf{List}
    \;\textcolor{red!70}{\dagger}
  }
\end{prooftree}
\caption{
  Main proof (Fig.~\ref{fig:cons-branch} completes the green cons premise).
  $\dagger$ = backlink; red = companion.
  \textsc{fix}: unfold $\mathsf{reverse}$.
  \textsc{lemma}: LLM cut (validated by sub-prover).
  \textsc{iota}: case reduction on $ys$; nil branch closed via \textsc{back}
  (substitution $ys\mapsto\mathsf{nil}$); cons branch (green) delegated to
  Fig.~\ref{fig:cons-branch}.
}
\label{fig:reverse-append-proof}
\end{figure}

\begin{figure}[t]
\centering\scriptsize
\begin{prooftree}
  \hypo{xs,ys \vdash \mathsf{reverse}\;xs : \mathsf{List}}
  \hypo{ys' \mapsto \mathsf{cons}\;y\;\mathsf{nil} \;:\; [ys'] \to_s [xs,ys]}
  \infer2[\textsc{back}\;\textcolor{red!70}{\dagger}]{
    \textcolor{red!60}{
      xs,ys \vdash \mathsf{revAcc}\;(\mathsf{cons}\;y\;(\mathsf{reverse}\;xs))\;\mathsf{nil}
      : \mathsf{List}
      \;\textcolor{red!70}{\dagger}
    }
  }
  \hypo{\textcolor{green!60!black}{\cdots\;\text{(induction on }ys''\text{)}}}
  \infer2[\textsc{iota}]{
    xs,y{:}\mathsf{Nat},ys' \vdash
    \mathsf{revAcc}\;ys'\;(\mathsf{cons}\;y\;(\mathsf{reverse}\;xs)) : \mathsf{List}
  }
\end{prooftree}
\caption{
  Cons branch (completes Fig.~\ref{fig:reverse-append-proof}).
  Same cyclic structure as the main proof, with $ys'$ in place of $ys$
  and $\mathsf{cons}\;y\;(\mathsf{reverse}\;xs)$ as the accumulator.
  The cycle repeats until the cons chain on $ys'$ reaches nil,
  at which point the backlink closes via $ys'\mapsto\mathsf{cons}\;y\;\mathsf{nil}$.
}
\label{fig:cons-branch}
\end{figure}
