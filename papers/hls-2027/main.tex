\begin{abstract}
Supercompilation is theorem proving.  Driving is cut elimination, generalisation
is cut introduction, and the trace condition is the global progress check of
cyclic proof theory.  This observation, made precise through mechanisation in
Rocq, leads to an architecture where program optimisation is outsourced to an
untrusted oracle and validated by a deterministic proof kernel.
The architecture is a framework for safe heuristic extension:
any oracle is admissible without affecting soundness, since the CIU
theorem depends only on the kernel's trace-condition check.

We implement this architecture with two oracle roles: (i)~an LLM proposes
generalisation cuts, validated by the kernel, making any heuristic admissible
without affecting soundness; (ii)~the same LLM proposes auxiliary lemmas, which
a sub-prover validates, enabling the $\omega$-rule --- strengthened induction
hypotheses that standard supercompilation cannot discover.  A controlled
scrambling experiment (6 programs, all function and type names randomised)
shows the LLM succeeds from term structure rather than name recognition.

The system proves 70+ theorems with 0 admitted: monad laws, insertion sort
correctness, compiler soundness, reverse-append distribution, and commutativity
of addition.  Two dependent-type extensions prune impossible constructors
from type indices and normalise vector length indices.
\end{abstract}
