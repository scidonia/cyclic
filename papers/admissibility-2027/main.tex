\begin{abstract}
Cyclic proofs close goals by backlinking to previously-seen configurations,
discovering induction principles post-hoc rather than prescribing them upfront.
We prove that backlinks are \emph{admissible} in the Calculus of Inductive
Constructions (CIC): every valid cyclic proof can be read back to a standard CIC
term that uses only the native fixpoint binder ($\fix$) for recursion
and is observationally indistinguishable from the root goal.  The proof is
a direct corollary of a contextual-equivalence theorem mechanised in Rocq with
0 axioms.
\end{abstract}

\section{Introduction}

Cyclic proof theory~\cite{brotherston-2006-cyclic,brotherston-simpson-2011-sequent}
extends standard proof systems with backlink rules that allow a premise to
reference a previous goal, forming a directed cycle.  The cycle is sound if
it satisfies a global \emph{trace condition}: every cycle must contain a
\emph{progress event}---a case-split on a structurally smaller term.
Brotherston and Simpson prove that for first-order logic with inductive
definitions, backlinks are \emph{admissible}: every cyclic proof corresponds
to a standard proof with an explicit induction rule.

This paper extends their result to the Calculus of Inductive Constructions
(CIC)~\cite{coquand-huet-1988-coc,paulin-mohring-1993-inductive}, the type
theory underlying Rocq.  We prove that every rooted, ranked cyclic proof
can be residualised to a standard CIC term using only $\fix$ for
recursion, and that the residual is observationally equivalent to the
root goal.

\section{Term calculus and reduction}

Terms are given by the grammar:
\[
\begin{array}{rcl}
t,u,A,B &::=& x \mid \Sort{i} \mid \Pi x{:}A.\,B \mid \lambda x{:}A.\,t \mid
            t\;u \mid \fix\, t \mid \Ind{I}{\vec{t}} \mid
            \Roll{I}{c}{\vec{t}} \mid \Case{I}{t}{\kappa}{\vec{b}}
\end{array}
\]
where $x$ ranges over de Bruijn indices, $i$ over universe levels,
$I$ identifies an inductive family, $c$ a constructor index,
$\kappa$ a dependent motive (a binder over the scrutinee), and
$\vec{t},\vec{b}$ are lists of terms.

We write $\to^*$ for the reflexive-transitive closure of $\to$, and
$t \Downarrow v$ (``$t$ terminates to $v$'') for $t \to^* v$ with $v$
a value (an abstraction, a constructor, or a neutral term).
Multi-argument application $\mathsf{apps}\;t\;[u_1,\ldots,u_n]$ is
defined inductively: $\mathsf{apps}\;t\;[] = t$ and
$\mathsf{apps}\;t\;(u :: \vec{u}) = \mathsf{apps}\;(t\;u)\;\vec{u}$.

\paragraph{Operational semantics.}
We use a call-by-name (CBN) reduction relation $t \to t'$ defined by:

\begin{itemize}
\item \textbf{$\beta$-reduction:}
  $(\lambda x{:}A.\,t)\;u \to t[u/x]$.

\item \textbf{Fixpoint unfolding:}
  $\fix\,t \to t[\fix\,t/0]$.  (The binder 0 in $t$ refers to the
  recursive self-reference.)

\item \textbf{$\iota$-reduction (case-of-constructor):}
  $\Case{I}{(\Roll{I}{c}{\vec{a}})}{\kappa}{\vec{b}} \to
    \mathsf{apps}\;(\vec{b}[c])\;\vec{a}$
  where $\vec{b}[c]$ selects the $c$-th branch.

\item \textbf{Congruence:} Reduction applies under applications and
  case scrutinees: if $t \to t'$ then $t\;u \to t'\;u$ and
  $\Case{I}{t}{\kappa}{\vec{b}} \to \Case{I}{t'}{\kappa}{\vec{b}}$.
\end{itemize}

A term $t$ \emph{terminates to} a value $v$, written $t \Downarrow v$,
if $t \to^* v$ and $v$ is in weak-head normal form (an abstraction,
a constructor, or a neutral term).

\section{Cyclic sequent calculus}

A \emph{configuration} is a typing judgement $\jTy{\Gamma}{t}{A}$.
A \emph{configuration graph} $b$ is a finite structure with
vertices $V = \{0,\ldots,n-1\}$, a labelling function
$\ell(b,\cdot) : V \to \mathsf{Config}$, a successor function
$\sigma(b,\cdot) : V \to V^*$, and a root vertex $v_0 \in V$.
A graph is a \emph{rooted pre-proof} if every vertex satisfies one of
the local rules below (read bottom-up):

\paragraph{Asynchronous rules (deterministic).} Applied eagerly.  Each
reduces the goal to a single premise by one computation step:

\medskip
\begin{prooftree}
  \hypo{\jTy{\Gamma}{t[u/x]}{A}}
  \infer1[\beta]{\jTy{\Gamma}{(\lambda x{:}A.\,t)\;u}{A}}
\end{prooftree}
\hspace{2cm}
\begin{prooftree}
  \hypo{\jTy{\Gamma}{t[\fix\,t/0]}{A}}
  \infer1[\textsc{fix}]{\jTy{\Gamma}{\fix\,t}{A}}
\end{prooftree}

\medskip
\begin{prooftree}
  \hypo{\jTy{\Gamma}{\mathsf{apps}\;(\vec{b}[c])\;\vec{a}}{A}}
  \infer1[\iota]{\jTy{\Gamma}{\Case{I}{(\Roll{I}{c}{\vec{a}})}{\kappa}{\vec{b}}}{A}}
\end{prooftree}

\paragraph{Synchronous rule (choice point).} A case-split on a neutral
scrutinee $x$ creates one premise per constructor $c$ of $I$,
each substituting the constructor pattern $\Roll{I}{c}{\vec{y}_c}$
for the scrutinee in the $c$-th branch, under an extended context
$\vec{y}_c$ of fresh variables for the constructor arguments:

\medskip
\begin{prooftree}
  \hypo{\jTy{\Gamma,\vec{y}_0}{b[0][\Roll{I}{0}{\vec{y}_0}/x]}{A}}
  \hypo{\cdots}
  \hypo{\jTy{\Gamma,\vec{y}_n}{b[n][\Roll{I}{n}{\vec{y}_n}/x]}{A}}
  \infer3[\textsc{split}]{\jTy{\Gamma}{\Case{I}{x}{\kappa}{\vec{b}}}{A}}
\end{prooftree}

\paragraph{Cyclic backlink (closure).}
\medskip
\begin{prooftree}
  \hypo{\Delta \vdash \sigma :_s \Gamma}
  \infer1[\textsc{back}]{\jTy{\Delta}{t}{A}}
\end{prooftree}
where there exists a vertex $v' \in V$ such that
$\ell(b,v') = \jTy{\Gamma}{t_0}{A}$ and $t = t_0[\sigma]$ is the
original goal under the substitution $\sigma$.

\paragraph{Global progress condition.}
A rooted pre-proof is a \emph{rooted cyclic proof} if every directed
cycle contains at least one \textsc{split} edge.  Formally, define the
\emph{budget-trace} graph $(V \times [0,|V|], E_B)$ where
$(v_1, k_1) \to (v_2, k_2)$ is an edge in $E_B$ iff $v_1 \to v_2$ is
an edge in the original graph and either:
\begin{itemize}
\item $v_1 \to v_2$ is a \textsc{split} edge and $k_2 = k_1 - 1$;
\item $v_1 \to v_2$ is any other edge and $k_2 = k_1$.
\end{itemize}
The graph is a valid cyclic proof iff the budget-trace graph is acyclic
(starting from $(v_0, |V|)$).  We write $\mathcal{C}(b,v_0)$ for this
property.

\section{Residualisation}
\label{sec:residualise}

The backlink rule appears only in the proof graph.  A \emph{residualisation}
function $\mathcal{R}(b,v)$ reads back the graph into a CIC term by
traversing the successors of $v$ and replacing backlinks with
$\fix$ binders.  Formally, $\mathcal{R}$ is defined by well-founded
recursion on the budget trace:

\begin{itemize}
\item If $v$ has no successors (leaf), $\mathcal{R}(b,v)$ returns the
  term $t$ where $\ell(b,v) = \jTy{\Gamma}{t}{A}$.
\item If $v$ has a single successor $w$ (asynchronous rule), then
  $\mathcal{R}(b,v) = D(\mathcal{R}(b,w))$ where $D$ applies the inverse
  of the driving step: re-abstracts $\beta$ reductions, re-applies the
  fix binder, re-constructs the case-of-constructor.
\item If $v$ has multiple successors $\vec{w}$ (split rule), each
  branch is residualised independently and combined into a
  $\Case$ application.
\item If $v$ is the \emph{target} of a backlink (some vertex has
  $v$ as its sole successor via a \textsc{back} edge), then
  $\mathcal{R}(b,v) = \fix\, t_{\mathrm{body}}$ where
  $t_{\mathrm{body}}$ is the residual of the backlink's source vertex
  with de Bruijn index $0$ replaced by the recursive self-reference.
\end{itemize}

The result is a well-typed CIC term using only standard constructors
($\lambda$, application, $\fix$, $\Case$,
$\Roll$).  No backlink constructs remain.

\section{CIU equivalence}

The soundness guarantee is \emph{CIU equivalence} (contextual
equivalence under all closing substitutions):
\[
  t \ciu u \;\equiv\; \forall \sigma, v.\; (t[\sigma] \Downarrow v \iff
  u[\sigma] \Downarrow v)
\]

Each local rule of the sequent calculus preserves CIU equivalence.
The asynchronous rules are invertible: the conclusion is CIU-equivalent
to its premise because each is a single reduction step ($\beta$, fix
unfolding, $\iota$).  The split rule preserves CIU through the case
analysis of a neutral scrutinee: substituting constructor patterns for
the scrutinee in each branch yields a CIU-equivalent configuration.
The back rule creates a fix binder at the target vertex.

\begin{theorem}[CIU soundness]
\label{thm:ciu}
If $b$ is a rooted, ranked cyclic proof with root $v$ and
$\ell(b,v) = \jTy{\Gamma}{t}{A}$, then
\[
  t \ciu \mathcal{R}(b,v).
\]
\end{theorem}

\begin{proof}[Proof sketch]
By well-founded induction on the budget trace.  Each edge preserves
CIU: asynchronous rules are single reduction steps, split preserves
CIU through a neutral scrutinee, and backlinks become recursive
self-references.  The residualiser $\mathcal{R}$ unions these
transformations across the graph.  Full details are mechanised in Rocq
(0~axioms) for the special case of graphs produced by the
supercompiler~\cite{esop-2027}; the same proof structure generalises
to any rooted, ranked cyclic proof because it depends only on the
local rules and the trace condition, not on the supercompilation
algorithm.
\end{proof}

\section{Admissibility}

\begin{theorem}[Backlink admissibility]
\label{thm:admissible}
For every configuration graph $b$ and vertex $v$,
\[
  \mathcal{C}(b,v)
  \;\Longrightarrow\;
  \exists\, t_{\mathsf{std}},\;
  t \ciu t_{\mathsf{std}}
  \;\land\;
  t_{\mathsf{std}} = \mathcal{R}(b,v)
\]
where $\ell(b,v) = \jTy{\Gamma}{t}{A}$.
\end{theorem}

\noindent In words: every rooted cyclic proof can be read back to a
standard CIC term (using only $\fix$ for recursion) that is
observationally indistinguishable from the root goal.

\begin{proof}
Take $t_{\mathsf{std}} = \mathcal{R}(b,v)$.  By construction
(Section~\ref{sec:residualise}), $t_{\mathsf{std}}$ uses only standard
CIC constructors---no backlinks remain.  The CIU equivalence
$t \ciu t_{\mathsf{std}}$ is Theorem~\ref{thm:ciu}.
\end{proof}

\noindent The mechanised proof (\texttt{BacklinkAdmissible.v}) derives
admissibility as a four-line corollary of the CIU theorem for
supercompiler-produced graphs; the proof sketch above covers the
general case for arbitrary cyclic proofs.

\section{Discussion}

The admissibility transformation is the same residualisation that the
proof graph already provides: traverse the graph, replacing backlinks
with $\fix$ binders.  The CIU theorem (proved for each local rule of
the sequent calculus) establishes equivalence; the residualiser
eliminates backlinks; the result follows immediately.

Compared to Brotherston and Simpson's result for first-order logic, our
proof is simpler because (a)~the graph is finite, and (b)~residualisation
is a syntactic transformation that explicitly replaces backlinks with
$\fix$, rather than requiring a semantic argument about proof
unfoldings.
