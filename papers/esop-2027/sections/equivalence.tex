\section{Main results}
\label{sec:equiv}

We organise the central results as a four-claim pipeline, each building on the previous. All results are fully mechanised in Rocq with 0 axioms; a mapping from theorems to artefact names and file paths is given in the appendix.

\subsection{Claim 1: Pre-proof correspondence}

\begin{theorem}[Pre-proof construction]
\label{thm:pre-proof}
For any environment $\Sigma$, fuel $f$, context $\Gamma$, term $t$, and type $A$:
\[
  \mathsf{supercompile\_jTy}\;f\;\Sigma\;\Gamma\;t\;A = \mathsf{Some}\,(v,\mathit{b})
  \;\Rightarrow\;
  \mathsf{rooted\_preproof}\; \mathit{b}\;v
\]
where $\mathit{b}$ is a $\mathsf{cfg\_builder}$ (a finite map from vertices to configurations plus successor and instantiation maps).
\end{theorem}

\paragraph{Proof sketch.} By construction of the supercompiler loop. The internal state records a memo table mapping configurations to vertices. Each step---driving, splitting, generalising, or memo lookup---corresponds to a sequent rule as defined in Section~\ref{sec:focused}. Driving steps satisfy the asynchronous rules (fixpoint unfolding, $\beta/\iota$-reduction); case splits on neutral scrutinees satisfy the synchronous left rule; memo hits satisfy the cyclic backlink rule; and generalisation steps satisfy the generalisation rule, with the generalised configuration forming a new vertex whose local rule is checked recursively. The three step-level correspondences (driving, splitting, folding) are proved independently at the graph level via a bisimulation relating supercompiler graph structure to sequent rule instances. The full correspondence is assembled by structural induction on the supercompiler fuel. Coq: \texttt{all\_supercompiled\_programs\_yield\_preproof} (SupercompilationCorrespondence.v:1659).

\subsection{Claim 2: Cyclic proof via budget trace}

\begin{theorem}[Cyclic proof]
\label{thm:cyclic-proof}
With the trace-condition check enabled:
\[
  \mathsf{supercompile\_jTy\_tc}\;f\;\Sigma\;\Gamma\;t\;A = \mathsf{Some}\,(v,\mathit{b})
  \;\Rightarrow\;
  \mathsf{rooted\_cyclic\_proof}\;\mathit{b}\;v
\]
where the ranking condition is satisfied by a budget-instrumented trace graph on pairs $(v,k)$.
\end{theorem}

\paragraph{Proof sketch.} The boolean trace check (\texttt{trace\_condition\_ok}) verifies that the non-progress graph (erasing outgoing edges from progress vertices) contains no directed cycles. Progress vertices are those whose configuration contains a case-split on a neutral scrutinee. The proof constructs a budget-instrumented graph: each vertex $v$ is lifted to pairs $(v,k)$ where $k \in [0,B]$ is a budget counter that is decremented on progress edges (case splits) and preserved on non-progress edges. Since every cycle in the original graph must contain at least one progress edge (by \texttt{trace\_condition\_ok\_cycle\_progress}), the lifted graph is acyclic. This acyclicity yields a ranking function $\lambda(v,k).\;k$, satisfying the global progress condition of the cyclic proof system. The construction is purely combinatorial: $\sim$500 lines for the graph-theoretic lemmas (FiniteDigraph, SCC detection, cycle extraction) and $\sim$200 lines for the budget instrumentation and ranking witness. Coq: \texttt{supercompile\_yields\_rooted\_cyclic\_proof} (SupercompilationCorrespondence.v:1694).

\subsection{Claim 3: CIU soundness}

\begin{theorem}[CIU equivalence]
\label{thm:ciu}
For any environment $\Sigma$, fuel $f_s$, fuel $f_r$, context $\Gamma$, term $t$, type $A$:
\[
  \mathsf{supercompile\_jTy\_tc}\;f_s\;\Sigma\;\Gamma\;t\;A = \mathsf{Some}\,(v,\mathit{b})
  \;\Rightarrow\;
  t \approx_{\mathrm{ciu}} \mathsf{residualise\_cfg}\;f_r\;\Sigma\;\mathit{b}\;v\;0\;\emptyset
\]
where $t \approx_{\mathrm{ciu}} u$ means: for all closing substitutions $\sigma$ and CBN values $w$, $t[\sigma] \Downarrow w$ iff $u[\sigma] \Downarrow w$.
\end{theorem}

\paragraph{Proof sketch.} By fuel induction on the residualiser, with the trace condition ensuring non-terminating self-loops are excluded. The residualisation function \texttt{residualise\_cfg} recursively traverses the configuration graph, reconstructing a term with explicit \texttt{tFix} binders for cyclic back-edges. For each constructor of the CBN term language ($\lambda$, application, case, fixpoint, inductive constructor), we prove a component lemma that CIU is a congruence:
\begin{itemize}[leftmargin=*]
\item \texttt{ciu\_tApp}: if $t \approx_{\mathrm{ciu}} u$ then $t\;\mathit{arg} \approx_{\mathrm{ciu}} u\;\mathit{arg}$ for any $\mathit{arg}$;
\item \texttt{ciu\_shift}, \texttt{ciu\_subst0}: CIU preserved under shift and substitution;
\item \texttt{ciu\_apps}: CIU preserved under multi-argument application;
\item \texttt{ciu\_case}: if branches are pairwise CIU-equivalent, the case expressions are CIU-equivalent;
\item \texttt{ciu\_of\_eq}: syntactic equality implies CIU (for the fold step).
\end{itemize}
The main theorem composes these lemmas: each residualisation step either preserves the original term (for non-backlink vertices) or introduces a \texttt{tFix} binder that is CIU-equivalent to the unfolded recursive call. The trace condition guarantees the residualiser terminates. The typed variant lifts the untyped CIU result through the typing judgements using the substitution lemma \texttt{ciu\_jTy\_of\_ciu\_jTy\_rel\_eq}. Coq: \texttt{supercompile\_ciu\_soundness\_untyped} (line~1808), \texttt{supercompile\_ciu\_soundness\_typed} (line~1877).

\subsection{Claim 4: Example validation}

\begin{proposition}[Examples]
\label{prop:examples}
The following examples pass the four-claim pipeline with computational equality verified by Rocq's \texttt{vm\_compute}:
length-map fusion ($\mathsf{length}\;(\mathsf{map}\;f\;l) = \mathsf{length}\;l$),
append-length normalisation ($\mathsf{length}\;(\mathsf{append}\;l_1\;l_2) = \mathsf{plus}\;(\mathsf{length}\;l_1)\;(\mathsf{length}\;l_2)$),
append-associativity via 2-pass supercompilation,
take-drop fusion ($\mathsf{length}\;(\mathsf{append}\;(\mathsf{take}\;n\;l)\;(\mathsf{drop}\;n\;l)) = \mathsf{length}\;l$),
nested map-map deforestation ($\mathsf{length}\;(\mathsf{map}\;f\;(\mathsf{map}\;g\;l)) = \mathsf{length}\;l$),
and vector-index normalisation ($\mathsf{Vec}\;A\;(\mathsf{length}\;(\mathsf{map}\;f\;l)) \equiv \mathsf{Vec}\;A\;(\mathsf{length}\;l)$ as an index equality).
\end{proposition}

\paragraph{Proof.} For each example, the supercompiler processes the input term and produces a residual. Computational equivalence is verified by \texttt{vm\_compute}, which reduces both the residual and the expected output to normal form and checks syntactic equality. This is not a proof of CIU for the example (that follows from Claim~3) but a validation that the supercompiler produces a residual whose normal form coincides with the expected optimised result.
